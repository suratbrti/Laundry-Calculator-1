# FT-02 Input Berat & Notifikasi Min. Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 8 (AC-01), Bagian 9 (TC-01, TC-03), Bagian 11 (store_info.minimum_charge_kg)

## Tujuan
Pengguna dapat memasukkan perkiraan berat cucian dalam kilogram dan langsung melihat apakah ketentuan batas minimal 3 kg diberlakukan.

## Alur
1. Kolom berat cucian dimulai dalam keadaan kosong.
2. Pengguna mengetik atau menempel angka berat (mendukung tanda koma maupun titik).
3. Jika berat valid lebih dari 0 dan kurang dari 3 kg, kotak pemberitahuan otomatis tampil menjelaskan bahwa berat ditagih menjadi 3 kg.
4. Jika pengguna menekan tombol kirim saat berat kosong, 0, atau minus, pesan error tampil di bawah kolom berat dan fokus pindah ke kolom tersebut.

## Data
- `STORE_INFO.minimum_charge_kg` (`3.0`)

## Aturan dan rumus
- Satuan: kilogram (kg).
- Nilai valid saat kirim: angka desimal `W_aktual >= 0.1` (tidak boleh kosong, `0`, atau negatif).
- Rumus berat ditagih: `W_ditagih = max(3.0, W_aktual)`.
- Jika `0 < W_aktual < 3.0`, status `isMinChargeApplied = true` dan `W_ditagih = 3`.
- Pemisah desimal input menerima `,` dan `.`. Tampilan berat memakai koma tanpa nol di belakang (contoh: `4,5` dan `3`).

## Input dan validasi
- Kolom `Estimasi Berat Cucian (kg)`:
  - Wajib diisi sebelum kirim pesanan.
  - `inputMode="decimal"`, `type="text"`, `name="weight"`.
  - Spasi di awal dan akhir dihapus saat validasi.
  - Pesan error jika kosong atau bukan angka valid atau `<= 0`: "Masukkan berat cucian minimal 0,1 kg, contoh: 2,5."

## Tampilan dan teks
- Label terlihat: `Estimasi Berat Cucian (kg)`.
- Teks bantuan singkat: `Minimal tagihan 3 kg per pesanan.`
- Saat `0 < W_aktual < 3`: panel status amber (`bg-amber-50 text-amber-800 border-amber-200`) dengan ikon informasi dan teks: `Berat di bawah 3 kg tetap dihitung 3 kg (ketentuan minimal toko).`

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| AC-01 / TC-01 | Berat `2.0` kg, paket Cuci Lipat (Rp6.000/kg), tanpa add-on | Berat ditagih = `3` kg, label min. charge 3 kg muncul, subtotal Rp18.000 | PRD AC-01, TC-01 |
| TC-03 | Berat kosong atau `0` kg lalu tekan kirim | Pengiriman diblokir, pesan error muncul di kolom berat, fokus pindah ke kolom berat | PRD TC-03 |
| TC-F2-01 | Berat `1,8` kg (pakai koma) | Sistem membaca `1.8` kg, berat ditagih = `3` kg | PRD BL-02 Kasus A |
| TC-F2-02 | Berat `3` kg tepat | Berat ditagih = `3` kg, notifikasi min. charge di bawah 3 kg tidak muncul | Tambahan |

## Di luar lingkup
- Batas berat maksimal per transaksi atau konversi satuan gram.

## Pertanyaan terbuka
Tidak ada (nilai awal kosong telah diputuskan pengguna).
