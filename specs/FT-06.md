# FT-06 WhatsApp Deep Link Button

Sumber PRD: Bagian 5 (BL-03), Bagian 6 (FT-06), Bagian 7 (Format Template WhatsApp), Bagian 8 (AC-04), Bagian 9 (TC-05), Bagian 10 (Constraints)

## Tujuan
Pengguna dapat memeriksa kelengkapan pesanan dan membuka ruang obrolan WhatsApp toko dengan pesan pesanan terformat otomatis sesuai hasil hitungan di layar.

## Alur
1. Pengguna menekan tombol `Kirim Pesanan ke WhatsApp` pada bilah bawah ponsel atau panel ringkasan desktop.
2. Sistem memvalidasi berat (`> 0`), nama pemesan, dan alamat penjemputan (jika Antar-Jemput aktif).
3. Jika ada error, pesan error tampil di kolom terkait dan halaman menggulir ke kolom error pertama serta memberi fokus.
4. Jika valid, sistem menyusun teks template WhatsApp persis seperti PRD, melakukan `encodeURIComponent`, dan membuka tautan `https://wa.me/<nomor>?text=<pesan>` di tab baru (`target="_blank"`, `rel="noopener"`).
5. Sistem juga menampilkan banner ringkas konfirmasi di layar dan pratinjau pesan agar pengguna bisa menyalin ulang bila aplikasi WhatsApp belum terpasang.

## Data
- `STORE_INFO.whatsapp_number` (`6281234567890` sebagai nomor contoh)
- Seluruh hasil kalkulasi dan input formulir

## Aturan dan rumus
- Urutan cek validasi:
  1. Berat aktual harus terisi dan `>= 0.1`
  2. Nama pelanggan (`trim()`) tidak kosong
  3. Jika `Antar-Jemput` aktif, alamat (`trim()`) tidak kosong
- Template pesan WhatsApp mengikuti PRD secara utuh:
```
Halo Admin Laundry, saya ingin memesan layanan laundry dengan rincian berikut:

*Nama:* [Nama Pelanggan]
*Layanan Utama:* [Cuci Lipat / Cuci Setrika / Cuci Setrika Ekspres]
*Estimasi Berat:* [X] kg (Berat Ditagih: [Y] kg)
*Layanan Tambahan:*
- Antar-Jemput: [Ya (+Rp 10.000) / Tidak]
- Pewangi Premium: [Ya (+Rp Z.000) / Tidak]

*Alamat Penjemputan:* [Alamat Lengkap / "Antar Sendiri ke Toko"]
*Catatan Khusus:* [Catatan khusus atau "-"]

*Estimasi Total Biaya:* *Rp [Total]*

_(Catatan: Total di atas adalah estimasi awal. Berat pasti akan ditimbang kembali saat pakaian diterima oleh kasir/kurir laundry)._

Mohon konfirmasi pesanan dan ketersediaan jadwalnya. Terima kasih!
```
- Seluruh isi pesan di-encode memakai `encodeURIComponent` agar karakter seperti `&`, `!`, baris baru, dan tanda bintang tetap aman di URL.
- Pembukaan tab baru dilakukan lewat elemen tautan `<a>` atau pembukaan aman tanpa `window.alert`/`window.open` yang memblokir (atau klik tautan terprogram dengan `rel="noopener"`). Catatan: pakai tombol aksi yang memicu pembukaan tautan atau merender link `https://wa.me/...` setelah validasi / langsung dengan `document.createElement('a')` ber-`target="_blank"` dan `rel="noopener noreferrer"` agar tidak memakai `window.open` dan tidak memicu peringatan environment!

## Input dan validasi
- Tombol `Kirim Pesanan ke WhatsApp` (minimal tinggi 44 px, latar `bg-blue-700 hover:bg-blue-800 text-white`, tanpa ikon panah di akhir label).

## Tampilan dan teks
- Label tombol: `Kirim Pesanan ke WhatsApp`.
- Setelah klik valid: tampil status berhasil hijau (`bg-emerald-50 text-emerald-800`) dengan teks `Tautan WhatsApp siap dikirim.` serta tombol cadangan `Salin Pesan` jika pengguna ingin menyalin manual.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| AC-04 | Data lengkap, Berat `4,5` kg, Cuci Setrika, Antar-Jemput + Pewangi | URL `https://wa.me/...` terbuka dengan total `55.000` dan rincian persis sama dengan layar | PRD AC-04, BL-02 Kasus B |
| TC-05 | Catatan: `Baju dinas & sutra, jangan dicampur!` | Parameter `text=` ter-encode aman (`%26`, `%21`) dan pesan utuh saat didecode | PRD TC-05 |
| TC-F6-01 | Berat `0`, Nama kosong | Pengiriman batal, fokus ke input berat | PRD TC-03 |

## Di luar lingkup
- Pengiriman pesan otomatis di latar belakang melalui WhatsApp Business API tanpa interaksi pengguna.

## Pertanyaan terbuka
Tidak ada (nomor contoh disetujui pengguna).
